# NumPy

This repository contains my NumPy learning, practice exercises, and a sales analysis project built using NumPy.

## Contents

### 1. NumPy Practice
`numpy_practice.py`

Contains practice questions covering important NumPy concepts such as:
- Creating and working with arrays
- Indexing and slicing
- Array attributes
- Mathematical and statistical operations
- Boolean filtering
- `where()`
- `argmax()` and `argmin()`
- Sorting
- Handling missing values (`NaN`)
- Reshaping
- Concatenation and array splitting
- Broadcasting
- Random number generation
- Basic linear algebra

### 2. Sales Analysis Project
`sales_analysis_numpy/`

A practical sales analysis project using a real-world-style sales dataset.

It includes:
- `sales_data.csv` — Sales dataset
- `project_questions.txt` — Project tasks
- `sales_analysis_numpy.py` — NumPy solutions

## Tools Used

- Python
- NumPy

## Goal

The purpose of this repository is to build practical NumPy skills for my journey toward becoming a Data Analyst.
